# Pooja's Portfolio

Static website (HTML, CSS, JavaScript). No build step needed.

## Files
- index.html: page content
- style.css: all styles
- script.js: code-card tabs and the email button setting
- images/pooja.jpg: profile photo
- .nojekyll: tells GitHub Pages to serve the files as they are

## Email button
The address is set on line 2 of script.js (`var EMAIL`). Change it there to update the Email buttons.

## Publish on GitHub Pages
1. Create a repository on github.com (for example `my-portfolio`), set to Public.
2. Upload everything inside this folder (index.html, style.css, script.js, images, .nojekyll, README.md) to the repository root.
3. Go to Settings > Pages. Under Build and deployment, choose "Deploy from a branch", branch `main`, folder `/ (root)`, then Save.
4. Wait one to two minutes. Your site is at https://poojaachar735-bit.github.io/my-portfolio/
